## 4. 环境与坑（浓缩，详版在 `.workbuddy/memory/MEMORY.md`）

- **WSL 唯一**：`wsl.exe -- bash <项目>/tools/_run.sh <脚本> [参数]`；
  `wsl.exe -- bash -lc '...$VAR...'` 的变量会被 Windows 层吃掉。
  `_run.sh` 有护栏：cwd 不在项目内直接 exit 3。**WSL 只许碰项目目录**。
- 缓存：解析缓存在 WSL 原生盘 `~/.cache/bil`（`tools/.cache` 是软链）。
  **`.cache/*` 永不删 = 缓存就是钱**。`build/`、`diag/` 用户自己删。
- node 用 nvm 那份（`tools/eqrender` 要 ≥20.9）；**绝不在 /mnt/c 上 npm i**。
- 截图验证：`msedge --headless=new --disable-gpu --window-size=900,2300
  --screenshot=out.png file:///…`（不启服务）。
- **别用 `git rm`**：本轮实测 `git rm` 被 SIGTERM 打断后 `.git/index.lock` 残留
  + 工作区 56 个文件被连带清掉（含 `_run.sh`/`run_book.py`）。
  恢复配方：`rm -f .git/index.lock` → `git status --porcelain | awk '$1=="D"{print $2}'
  | xargs git checkout HEAD --`。要删文件就用普通 `rm` + `git add <路径>`。
- 代码整理时留下的**零引用探针**（可删，本轮没删是为了避开上面的雷）：
  `tools/dbg_heads2.py dbg_fig.py dbg_fig2.py dbg_wide2.py dbg_skew.py

| 同上 + 标题位置推算 | 「6.5 节有 373 条只英文」 | 6.5 节**结构完全正确**，是区间定位偏了 |

**正确做法（写进工具约定）**：
- 数结构**只数标签**（`re.findall(r'<p class="zh[^"]*"', t)`），**不做嵌套配对**；
- 要按区间统计，**用「下一个标题/下一个 pair 起点」做边界**，绝不用 `.*?</div>`；
- 任何"疑似结构性缺陷"的结论，**必须回到原始 HTML 看 300 字节**再下判断。

### 6.17 ★★ 两个解析器 bug —— 用户点名的「对齐错配」八成是它（2026-09-18 12:xx）

#### Fix #1：CSS 类名标题漏 `h2a`（`tools/bil/epubparse.py`）

**病象**：`prob_en.epub` 里有 5 处 `class="h2a"` 的小节标题被**降级成正文**。

# 旧（错）：class="h2a" 不匹配 → 标题变正文
_CLASS_HEAD_RE = r"(?:^|[\s_-])h([1-6])(?:[\s_-]|$)"
# 新（对）：允许 h1–h6 后跟一个可选字母（h2a / h2b / h1a / h3a）

#### Fix #2：md 附录的**裸行子节标题**（`tools/bil/txtimport.py`）

**病象**：中文 md 的附录里，子节标题是**没有 `#` 前缀的裸行**：

```
A.1 柯尔莫哥洛夫概率系统        ← 裸行，无 # 无粗体
```

`_MD_HEAD_RE`（要有 `#`）和 `_bare_head`（≤12 字、且必须全长匹配 `_ZH_HEAD_RE`）
**两条都不认** → 整个附录被解析成 **1 个 section**（中文 88 段 vs 英文 6 节）。
这正是 §6.16 (2) A 类「附录整章未译」的**真身**。

**修法**：新增一个**只认附录子节**的裸行判据，命中后**在当前文档内**追加
一个 `level=2` 的 heading 块（**不开新文档**）：

```python
_APX_SUBHEAD_RE = re.compile(r"^([A-Z])\.(\d{1,2})(?:\.\d{1,2})?\s+\S")

def _bare_subhead(line: str, lang: str) -> str:
    """裸**子节**标题（附录 A.1 / B.3 …）。命中返回标题文本，否则空串。"""
    if lang != "zh":
        return ""
    t = (line or "").strip()
    if not t or len(t) > 60:
        return ""
    if not _APX_SUBHEAD_RE.match(t):
        return ""
    if t.endswith((".", "。", ",", "，", ";", "；", ":", "：")):
        return ""
    return t
```

⚠ **为什么不用「加进 `_ZH_HEAD_RE`」**：那会把 `###` 级也判成章、把单元切碎
（§6.6 已经警告过）。这里必须**只做 heading 块、不开新单元**。

真正会毁整节的只有：**块数差**（整体错位一格）、**多对占比过高**、
