## 一、实测事实（设计依据，2026-09-14 深夜三路探针）

### EN 侧（《概率论沉思录》，EPUB2 + toc.ncx）

| 来源 | 实测结果 | 用途 |
|---|---|---|
| `toc.ncx`（366 条，无 nav.xhtml） | **三层完整**：L2 部分 → L3 `x.y` → L4 `x.y.z`；且 href 带正文锚点 id（`11_Chapter02.html#h2_2.6.2`）→ **目录免费送正文定位** | 标题链主源 |
| 正文 HTML | 本书**无 h1-h6 标签**，全部标题 = `<p class="h1">`/`<p class="h2">`，共 11 块（chapter-title×1 + h1×6 + h2×4），解析已全部识别 | 标题链校验源 |
| `<title>` 标签 | 只有书名，无用 | 忽略 |

**关键结论：EN 提取 2.6.1 完全成功，坏在 `split_sections` 按众数层级（L1）切分时把 L2 拍平**（EN 7 节 vs ZH 11 节的根源）。提取与切分是两件事。

### ZH 侧（prob_zh.md，minerU + 手工整理）

- **所有标题都是 `###`**（2.1 和 2.6.1 同级）→ `#` 数量不可信；
- 但**编号在标题文本里**（`2.6.1 主观与客观`）→ 编号才是可靠信号；
- **md 自带倒装**：2.6.4 排在 2.6.3 前 → 标题匹配必须**按编号**，不能按位置；
- 独立行间公式段已标 `type="formula"`（is_visual，不进 DP）。

### 其它书的不确定性（用户实测多个网友制书）

- 标题可能出现在 `<title>`、`h1~h4`、或 `class="calibre7"` 的 `<p>`（如《思考快与慢》）——**单一启发式保证不了全覆盖**；
- 目录页不一定含小节；交叉引用不一定存在；
- ⇒ 必须**多级兜底**，不能赌任何单一来源。

## 二、策略（用户定稿，2026-09-15 00:05）

### 第 1 步：标题链精确对齐（主力）

1. **提取完整标题树，两侧各自独立**：
   - EN：`toc.ncx` / `nav.xhtml` 树（保留层级 + href 锚点 id）⊕ 正文标题块（h1-h6 标签、`epub:type`、class 语义、calibre 类启发式）；
   - ZH：md 里 `#`~`######` **全部提取**（不管几级、不管层级对不对），编号与文本为主；
2. 两棵树**按编号跨语言配对**（`2.6.1` 层级编号正则；章号 `第N章`/`Chapter N`），编号是最稳的跨语言信号；
3. 配不上的（缺号/译法差异/层级错乱）→ **把两棵完整标题链发给 LLM 分组映射**，明确告知"层级可能不准，以编号和文本相似度为准"——全量标题给 LLM 提供容错空间；
4. 配上的标题对 = **硬锚**：锁死小节边界，小节内段落对齐不再跨界。

### 第 2 步：等分推进（兜底，用户方案；2026-09-15 02:2x 补三个钉死的细节）

前提：章已对齐。若小节级仍对不上（无标题/标题链残缺）：

1. 把章内段落**按等分划块**（每块 ≥20 段；两边段落数应大致等长，等分近似成立）；
2. 每块**前后各带 ~3 段余量**发给 LLM，直接做段落对齐（区间行格式）；
3. **第一批确认的边界成为第二批的锁定前缀**——第二批只在已确认边界之后取 20 段+余量；
4. 本质 = 最长已确认前缀逐步推进：窗口大小可控 → 收敛、防幻觉、错误不跨块传播。

**三个必须钉死的细节（不然有暗坑）：**

- **① 按累计长度等分，不按段数**。两侧段落数经常不等（ch2: EN 224 vs ZH 336），
  且局部密度不均（公式密集区中文段少）。正确做法：两侧各自按「累计长度占比」切——
  EN 用词数、ZH 用字数，各切在自己总量的 k/N 处。这比按段数等分抗密度波动。
- **② 边界「干净」才锁定，不干净就扩窗**。倒装（实测 md 里 2.6.4 排在 2.6.3 前）
  会让块尾出现成片「无对应」的 EN 段、块首出现成片「无对应」的 ZH 段。
  规则：块尾 EN 未匹配比例 > 阈值（如 30%）⇒ 该边界**不锁**，下一窗把起点
  回退覆盖这段尾巴（窗变长一点）；只有两侧边缘段都配上对，边界才锁死。
- **③ 已确认边界的实际位置回填**。第二块不用理论等分位置，用第一块确认出的
  实际 EN/ZH 段号做起点——理论位置只用于**初始猜测**，实际位置逐步覆盖它
  （自校正，漂移不累积）。这就是「最长已确认前缀」的本义。

**成本账**：每块 ≈ 3.5K 输入 tok；一章 224 段 ≈ 8 块 ≈ 28K tok ≈ **¥0.04~0.06/章**
（空闲价）。只有标题链失效的章才走这条，不是全书成本。

### 第 3 步：段落级细排

窗内 1:1 / 1:N / N:1 段落对齐（现有 `refine_window`，区间行格式待验证）→
格式对齐与排版处理（公式/代码/图表挂载）沿用现有 build。

### 锚点可靠性排序（全策略的优先级骨架）

```
① 标题编号链（TOC⊕正文双源） ★★★ 精确，主力
② 交叉引用（图/表/式号）     ★★☆ 学术书，只当分割器
③ 等分推进 + 渐进确认        ★★☆ 万无一失的兜底（用户方案）
④ DP 临时配对               ★☆☆ 只作参考，不再作定位依据
⑤ 顺序兜底                   最后手段
```
