## 3. 本轮踩到的坑（别重蹈）

1. **指标好 ≠ 内容对**。ML 那 7 个章挂着假中文，`dbg_bookscan` 照样报「缺中文 0」。
   现在 bookscan 报「缺中文 1」反而是**门禁变严了**（ch25 露出来了），不是回归。
2. **"产物是不是这条路建的"要靠产物指纹，不能靠记忆**。
   一行查：`grep -o 'class="pair"><p class="[a-z]*' <成品.html> | head -3`
   → `en` 在前 = unified，`zh` 在前 = legacy。
3. **改章映射前先 `dbg_chmap.py --book X` 看映射来源**（`key` 还是 `seq`）。
   ML 走 `key`、prob/think2 走 `seq`，两条路互不相干。
4. **`git commit` 成功 ≠ ref 落盘**（铁律 13，本轮触发 **5 次**）。
   commit 后必须 `git log --oneline -1` 复核；报 "does not have any commits yet"
   就去 `.git/logs/HEAD` 捞 SHA，再 `mkdir -p .git/refs/heads/feat` +
   `printf '%s\n' <SHA> > .git/refs/heads/feat/unified-immersive`。
   `git update-ref` **不管用**（rc=0 但不写文件），Write 工具写也时灵时不灵。
5. **Windows → WSL 传参会吃掉反斜杠和竖线和 heredoc**。
   `Figure\s+1-2` → `Figures+1-2`；`-c 'python - <<EOF'` 直接语法错。
   **只能写真实的 .py 文件再调 `_run.sh`**。
6. **`trace.jsonl` 每次访问都追加一行（命中也记）**，统计花费必须先 `if d.get("hit"): continue`，
   否则把"读缓存"当成"真调用"，能凭空多报几百次。
