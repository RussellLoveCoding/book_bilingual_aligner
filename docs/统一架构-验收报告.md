## 5. 复现方式

```bash
# 建一本（输出在 .workbuddy/tmp/full_uni_<书名>.log，终端看不到是正常的）
bash tools/run_full_uni.sh ml     .workbuddy/tmp/books/ml_en.epub     .workbuddy/tmp/books/ml_zh.epub     diag/ml_full_uni
bash tools/run_full_uni.sh prob   .workbuddy/tmp/books/prob_en.epub   .workbuddy/tmp/books/prob_zh.md     diag/prob_full_uni
bash tools/run_full_uni.sh think2 .workbuddy/tmp/books/think2_en.epub .workbuddy/tmp/books/think2_zh.epub diag/think2_full_uni

# 四道门禁一起跑
bash tools/gates_uni.sh diag/ml_full_uni diag/prob_full_uni diag/think2_full_uni
```

- 全部**不开 AI 补译**（跟老架构全书同策略，也避免 LLM 整本开火烧钱）。
- 回归：`bash tools/_run.sh regress.py`（三本无变化）；单测 125 例全绿。
